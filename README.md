# Отчёт по лабораторной работе №3: Линейные модели

1. Данные и подготовка

Используемые датасеты:
- `Student_Performance.csv` — данные об успеваемости студентов. Целевая переменная: `Performance Index` (числовая). Признак `Extracurricular Activities` (категориальный, Yes/No) приведён к числовому виду через one-hot кодирование.
- `german.csv` — данные о кредитоспособности клиентов. Целевая переменная `Creditability` находится в первом столбце (0 или 1).

Подготовка данных:
1. Категориальные признаки закодированы через `pd.get_dummies(drop_first=True)` — создаются бинарные столбцы для каждой категории.
2. Все числовые признаки масштабированы с помощью `StandardScaler` (вычитание среднего, деление на стандартное отклонение). Это необходимо для сходимости градиентного спуска и корректной работы KNN.
3. Данные разделены на train/test в соотношении 80/20 с `random_state=42`.



 2. Гипотезы и эксперименты

Гипотеза 1: Линейная регрессия с градиентным спуском сойдётся за 800 эпох при `learning_rate=0.05`.
- Результат: MSE монотонно убывал в процессе обучения. Итоговая MSE на тестовой выборке: 4.0826.

Гипотеза 2: Собственная логистическая регрессия покажет ROC-AUC выше 0.7.
- Результат: ROC-AUC = 0.7920, что значительно выше порога.

Гипотеза 3: Собственная реализация даст результаты, сопоставимые со sklearn.
- Результат: ROC-AUC собственной модели и sklearn совпадают (0.7920), accuracy различается незначительно (0.755 vs 0.750).

Гипотеза 4: Decision Tree покажет высокую precision, но худший ROC-AUC.
- Результат: подтвердилась — precision = 0.8387 (лучший среди всех), ROC-AUC = 0.7155 (худший).

Гипотеза 5: KNN покажет средние результаты.
- Результат: ROC-AUC = 0.7483, accuracy = 0.73 — средние показатели.

4. Выводы

1. Собственная реализация градиентного спуска корректна: метрики собственной логистической регрессии практически идентичны sklearn (ROC-AUC 0.7920 в обоих случаях).
2. Линейная регрессия успешно обучилась: MSE = 4.0826 на тесте, переобучения не наблюдается.
3. Логистическая регрессия — лучшая модель для задачи кредитоспособности: лучший ROC-AUC (0.7920), accuracy (0.755) и F1 (0.8339).
4. Decision Tree дал лучшую precision (0.8387), но худший ROC-AUC (0.7155) — склонен к переобучению.
5. KNN показал средние результаты; масштабирование данных критически важно для его работы.


5. Воспроизводимость

- Использован `random_state=42` при разделении данных и во всех моделях sklearn.
- Веса собственной модели инициализированы нулями (детерминированно).
- `StandardScaler` обучается только на train (`fit_transform`), на test применяется `transform` — утечки данных нет.
- Все метрики автоматически сохраняются в `experiment_results.json` при запуске функций.
- Внутри собственных моделей (`train_linear_regression`, `train_logistic_classifier`) не используются готовые модели sklearn — градиентный спуск реализован вручную на NumPy.
